# 怎么把手机连上电脑

连上之后我就能在**真机**上跑同一套端到端脚本，验厂商 ROM 那些模拟器给不了答案的东西
（省电策略、无障碍「受限设置」、无线调试限制、su 行为）。

电脑这边的 adb 已经装好了，在：
`dsh-mobile/toolchain/android-sdk/platform-tools/adb.exe`

---

## 方式一：USB 线（推荐，最稳）

### 1. 手机打开开发者选项

设置 → 关于手机 → 连续点「版本号」7 次 → 提示"已进入开发者模式"。

各家位置略有不同：

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi | 设置 → 我的设备 → 全部参数 → 连点「MIUI 版本」7 次 |
| 华为 / 荣耀 | 设置 → 关于手机 → 连点「版本号」7 次 |
| OPPO / 一加 / realme | 设置 → 关于本机 → 版本信息 → 连点「版本号」7 次 |
| vivo / iQOO | 设置 → 系统管理 → 关于手机 → 连点「软件版本号」7 次 |
| 原生 / Pixel | 设置 → 关于手机 → 连点「版本号」7 次 |

### 2. 打开 USB 调试

设置 → 系统 → 开发者选项（小米在「更多设置」里）→ 打开 **USB 调试**。

额外注意：

- **小米**：还要打开 **「USB 调试（安全设置）」**，否则改不了东西，只能读
- **OPPO / vivo**：可能要登录账号才允许开
- **华为**：可能需要在「开发者选项」里额外开「仅充电模式下允许 ADB 调试」

### 3. 插线

用**数据线**（很多充电线只有电源针脚，插上认不出来），插到电脑 USB 口。

### 4. 手机上点「允许」

手机弹出**「允许 USB 调试吗？」** → 勾选「一律允许使用这台计算机进行调试」→ 确定。

没弹窗的话：拔掉重插，或者开发者选项里点「撤销 USB 调试授权」再插一次。

### 5. 电脑上确认

```powershell
cd C:\Users\1\Documents\deepseek-harness\default-workspace\dshs
. .\tools\env.ps1
& $ADB devices
```

看到类似这样就成了：

```
List of devices attached
a1b2c3d4        device
```

`unauthorized` = 手机上没点允许；`offline` = 换线/换口；空列表 = 驱动问题（Windows 可装手机厂商的 USB 驱动）。

## 方式二：无线调试（Android 11+，不用线）

手机和电脑要在**同一个 WiFi**。

1. 设置 → 开发者选项 → 打开 **无线调试**
2. 点「**使用配对码配对设备**」，会显示 `IP:端口` 和 6 位配对码（页面别关）
3. 电脑上：

```powershell
. .\tools\env.ps1
& $ADB pair 192.168.1.23:37123      # 换成手机上显示的 IP:端口
# 提示输入配对码，输入那 6 位
& $ADB connect 192.168.1.23:5555    # 端口看无线调试主页显示的「IP 地址和端口」
& $ADB devices
```

**注意**：无线调试在**重启后默认关闭**，每次开机要重连一次。

## 连上之后

告诉我一声，我会跑：

1. `adb install DSHS.apk` —— 装到真机
2. 用真 key 跑一轮（你那条 key 我会先让你换新的，或者你给一条专门的测试 key）
3. 验厂商差异：无障碍能不能开、开了会不会被省电策略杀、`ui_dump` 读到的树和模拟器差多少
4. 如果这台机器被 root 了，再验 `sh` 那一档

---

## 真机上和模拟器不一样的两件事（先说清楚）

1. **`adb root` 不可用**。模拟器能 `adb root` 所以我脚本里能直接读 `/data/data/com.dshs/files/audit.log`；
   真机（非 root）读不到。真机验证只能到 UI 层——账本、工具卡、审计条数都在界面上，够看，但读不到原文。
2. **`su` 只有 root 过的机器才有**。没 root 的机器上 `sh` 工具按设计根本不出现（`shell` 能力档位是 ROOT）。

---

## 安全提醒

开 USB 调试等于给这台电脑**完全控制手机的权限**（能装应用、读数据、模拟点击）。
在别人的电脑上调试完记得：

```powershell
& $ADB kill-server
```

并在开发者选项里点「撤销 USB 调试授权」。
